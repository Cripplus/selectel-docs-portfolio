3. Инфраструктурная связка Selectel
3.1 Используемые продукты
VPC (Virtual Private Cloud) — приватная сеть для всех ресурсов.

Cloud Compute — сервер приложения и сервер базы данных.

S3‑совместимое объектное хранилище — для файлов, логов и бэкапов.

3.2 Почему они совместимы
Все ресурсы разворачиваются внутри одной VPC.

Облачные серверы подходят для размещения БД.

S3‑хранилище поддерживает Amazon S3 API.

Внутренний трафик между продуктами бесплатен и работает в рамках одной сети.

3.3 Схема
Код
+-----------------------------+
|         VPC (private)       |
+-----------------------------+
        |               |
+-------+-----+   +-----+-------+
| App Server |   | DB Server    |
| (Compute)  |   | PostgreSQL   |
+-------------+   +-------------+
        |
        | HTTPS / S3 API
        |
+----------------------+
|   S3 Object Storage  |
+----------------------+

5. Разница между микросервисами и монолитом
5.1 Монолит
Одно приложение, объединяющее весь функционал.

Код
+--------------------------------------+
|        Монолитное приложение         |
|--------------------------------------|
|  Каталог | Корзина | Оплата | Профиль|
+--------------------------------------+
|              Одна БД                 |
+--------------------------------------+
5.2 Микросервисы
Независимые сервисы, каждый отвечает за свою часть.

Код
        +-------------+       +-------------+
        |  Каталог    | <---> |  Корзина    |
        +-------------+       +-------------+
               |                     |
        +-------------+       +-------------+
        |   Оплата    | <---> |  Профиль    |
        +-------------+       +-------------+
               |
        +-------------+
        |   S3 / БД   |
        +-------------+
6. Вводный раздел к инструкции «Управлять ключами доступа»
Ключи доступа — это пара идентификаторов (Access Key и Secret Key), которые позволяют приложениям безопасно взаимодействовать с API и S3‑хранилищем без использования логина и пароля.
Они применяются для автоматизации загрузки и скачивания файлов, интеграции внешних сервисов, резервного копирования и других операций.

Ключи дают те же права, что и ваш аккаунт или назначенная роль, поэтому их важно хранить в безопасном месте. При необходимости ключи можно отозвать и создать новые.
