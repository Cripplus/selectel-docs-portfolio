# Как создать виртуальную машину в Selectel и подключиться по SSH
Это руководство поможет вам создать первую виртуальную машину (ВМ) в облачной платформе Selectel. Вы узнаете, как запустить инстанс с Ubuntu, настроить сетевой доступ и подключиться к нему по SSH с вашего локального компьютера
## Предварительные требования
*   Аккаунт в [панели управления Selectel](https://my.selectel.ru) (если нет, зарегистрируйтесь).
*   Положительный баланс на счету или активированный триальный период.
*   SSH-клиент:
    *   Для **Windows**: PuTTY, Windows Terminal (с WSL) или Git Bash.
    *   Для **macOS/Linux**: встроенный терминал.
    ## Шаг 1. Вход в панель управления
    Откройте my.selectel.ru и войдите в аккаунт.
    ## Шаг 2. Создание инстанса
    В панели управления перейдите в раздел **Облачная платформа → Виртуальные машины**.
Нажмите кнопку **"Создать сервер"**.
Настройте параметры:
*   **Имя сервера:** `my-first-server` (используйте латиницу).
*   **Операционная система:** Выберите **Ubuntu 22.04 LTS**.
*   **Конфигурация:** Выберите тариф `st-1-2-5-50` (1 ядро, 2 ГБ RAM, 5 ГБ SSD).
*   **Зона доступности:** Оставьте по умолчанию (`ru-9a`).
*   **Сеть:** Выберите публичную сеть `ext-net` (для доступа из интернета) и приватную сеть (если доступна).
## Шаг 3. Настройка ключей SSH (Безопасность)
Ключи SSH нужны для безопасного подключения без пароля. Если у вас еще нет ключа, создайте его в терминале командой ssh-keygen -t rsa.
В панели управления выберите вариант "Добавить новый ключ" и вставьте содержимое вашего публичного ключа (обычно файл ~/.ssh/id_rsa.pub).
## Шаг 4. Финализация и запуск
Нажмите кнопку "Создать сервер". Дождитесь, пока статус инстанса изменится на ACTIVE (обычно 1-2 минуты). Запишите публичный IP-адрес, который присвоился вашей машине.
## Шаг 5. Подключение по SSH
Откройте терминал на вашем компьютере и выполните команду. Замените xxx.xxx.xxx.xxx на IP-адрес вашего сервера.
```bash
ssh ubuntu@xxx.xxx.xxx.xxx
```
При первом подключении система спросит подтверждение подлинности хоста. Введите yes.
Если все настроено верно, вы увидите приглашение командной строки удаленного сервера (например, ubuntu@my-first-server:~$).
## Что дальше?
Поздравляю! Вы создали виртуальную машину и подключились к ней. Теперь вы можете устанавливать программное обеспечение, настраивать веб-сервер или разворачивать приложения.
